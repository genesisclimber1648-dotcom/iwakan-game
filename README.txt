違和感ハンター（20ステージ版）

■ 起動
index.html をブラウザで開いてください。

■ 遊び方
画像の違和感がある部分をクリック／タップします。
正解すると次のステージへ進みます。
同じ画像で3回間違えるとゲームオーバーです。

■ オーナー用：隠し編集モード
友人向け画面には「当たり判定を調整」ボタンを表示しない仕様です。

【スマホ／タブレット】
タイトル画面の「違和感ハンター」というタイトル文字を
3.5秒以内に7回タップすると編集モードが開きます。

【PC】
Ctrl + Shift + E
Macでは Command + Shift + E
で編集モードが開きます。

編集モードでは画像をドラッグして正解範囲を設定できます。
設定値はブラウザの localStorage に保存されます。


■ サウンド
ゲーム開始後にミステリアスなBGMがループ再生されます。
正解・不正解・ゲームクリア・ゲームオーバーには派手な効果音が鳴ります。
ブラウザの自動再生制限に対応するため、最初のボタン操作後に音が開始します。


■ BGM
ミステリアスBGMは assets/mystery_bgm.wav をループ再生します。
ゲームスタートのクリック／タップをきっかけに再生されます。
